# 小朋友存錢筒（Google Sheet + Apps Script + GitHub Pages）

一個小孩、多位長輩共用的虛擬存錢帳本。
- **長輩端**（爺爺、奶奶、爸、媽）：用 Google 帳號登入，可以給錢、扣錢、記錄任務完成；明細全部看得到，但只能撤銷自己記的。
- **管理員**（爸媽）：另外可以記錄花費、兌換獎品、設定任務／獎品／目標、新增成員，也能撤銷任何人的紀錄。
- **小孩端**（iPad 桌面 PWA）：用唯讀專屬連結開啟，只看得到總存款、目標進度和集章卡，不能修改。
- **月息**：每月 1 日凌晨 1–2 點，依當下存款自動發息。預設是每滿 1,000 元給 10 元，可以在設定頁修改。

```
docs/                ← GitHub Pages 網站（前端）
  index.html         長輩／家長端
  kid.html           小孩端（唯讀）
  config.js          ★ 部署後填入 API_URL、CLIENT_ID
  icons/
apps-script/
  Code.gs            ★ 貼到 Apps Script
  appsscript.json    （選用）時區與部署設定
```

## 架構與安全性

```
長輩手機 ──Google 登入──▶ ID token ──┐
                                      ▼
GitHub Pages（靜態網頁）──fetch──▶ Apps Script（以擁有者身分執行）──▶ Google 試算表（只有你能開）
                                      ▲   └ 向 Google 驗證 token，再查 Users 表決定權限
iPad 小孩端 ──唯讀 token────────────┘
```

- 試算表**不分享給任何人**。所有讀寫都經過 Apps Script，權限在後端檢查，不是只把前端按鈕藏起來。
- 流水帳**只新增、不刪除**。撤銷的做法是新增一筆反向紀錄，原紀錄保留，所以每一筆都查得到是誰記的。
- 小孩連結本身就是一組密碼。拿到連結的人只能「看」存款，不能改。萬一外流，到「設定 → 重新產生」，舊連結會立刻失效。

## 部署步驟（約 30 分鐘）

### 步驟 1｜建立試算表與 Apps Script
1. 到 Google Drive 新增一個空白試算表，命名為「小朋友存錢筒」。
2. 選單「擴充功能 → Apps Script」。
3. 把 `apps-script/Code.gs` 的全部內容貼上，取代預設的程式碼，然後存檔。
4. 左側「專案設定」：時區選 **(GMT+08:00) 台北**。
5. 上方的函式選單選 `setup`，按「執行」。
   - 第一次執行會要求授權。這是你自己的程式，所以會看到「Google 尚未驗證」：按「進階 → 前往（不安全）」並允許。只有你需要做這一步，長輩不會看到這個畫面。
   - 執行完，試算表會出現 Users、Ledger、Tasks、Rewards、Goals、Settings 六個分頁，你的帳號會自動成為管理員（顯示名稱預設「爸爸」，之後可以改）。

### 步驟 2｜建立 Google 登入用的 OAuth 用戶端 ID
1. 打開 <https://console.cloud.google.com/>，建立新專案，例如 `kids-savings`。
2. 「Google Auth Platform」（舊版介面叫「OAuth 同意畫面」）：
   - 應用程式名稱填「存錢筒」，使用者支援 email 填你的 Gmail。
   - 目標對象選 **外部**。
   - 發布狀態有兩種選法：
     - **測試中**：只有你加進「測試使用者」名單的 Gmail 能登入（上限 100 人）。家人少就用這個最簡單。
     - **發布到正式版**：只用到 email／基本資料這類基本範圍，通常不需要送 Google 審查。
3. 「用戶端 → 建立用戶端」：
   - 應用程式類型選 **網頁應用程式**。
   - 已授權的 JavaScript 來源填 `https://你的GitHub帳號.github.io`（不要加路徑、結尾不要斜線）。
   - 建立後複製「用戶端 ID」，格式是 `xxxx.apps.googleusercontent.com`。
4. 回到 Apps Script →「專案設定 → 指令碼屬性」，把 `CLIENT_ID` 的值改成剛才複製的用戶端 ID。

### 步驟 3｜部署 Apps Script 成 API
1. Apps Script 右上「部署 → 新增部署作業」。
2. 類型選「網頁應用程式」。
   - 執行身分：**我**
   - 誰可以存取：**所有人**
3. 部署完成後，複製結尾是 `/exec` 的網址。
4. ⚠️ 以後只要修改 Code.gs，都要到「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本」重新部署，網址才會維持不變。如果按「新增部署作業」，會產生新網址。

### 步驟 4｜上傳到 GitHub Pages
1. 編輯 `docs/config.js`，填入：
   - `API_URL`：步驟 3 的 /exec 網址
   - `CLIENT_ID`：步驟 2 的用戶端 ID
2. 把整個專案推到 GitHub repo（例如 `kids-savings`）。
3. repo 的「Settings → Pages」：Source 選 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/docs`。
4. 大約 1 分鐘後網站上線：
   - 長輩端：`https://你的帳號.github.io/kids-savings/`
   - 小孩端：用管理員帳號登入後，到「設定」頁取得 QR code 或連結。

### 步驟 5｜加入家人
1. 用管理員帳號登入長輩端 →「設定 → 成員 → 新增」，填入爺爺、奶奶、媽媽的 Gmail 和顯示名稱。媽媽的角色選「管理員」。
2. 如果步驟 2 選「測試中」，記得把這些 Gmail 也加進 Google Cloud 的「測試使用者」名單。
3. 把長輩端網址傳給家人。建議他們在 Safari 或 Chrome 加書籤。

### 步驟 6｜iPad 小孩端
1. 在 iPad 上用 **Safari** 掃描設定頁的 QR code，或打開小孩連結。
2. 按分享按鈕 →「加入主畫面」。
3. 小孩之後從桌面的小豬圖示開啟就好。每次回到 App 會自動更新，開著不動時每 5 分鐘也會自動更新。

## 使用規則

| 操作 | 長輩 | 管理員 | 說明 |
|---|---|---|---|
| 給錢／扣錢 | ✓ | ✓ | 來源會記成操作者的顯示名稱，例如「爺爺」 |
| 任務完成 | ✓ | ✓ | 每次給固定金額；完成次數達到集章目標時自動加碼 |
| 花費 | ✗ | ✓ | 必填「買了什麼」 |
| 兌換獎品 | ✗ | ✓ | 扣除獎品金額 |
| 達成目標 | ✗ | ✓ | 存款達到目標金額才能按，會扣款並標記完成 |
| 撤銷 | 自己記的 | 全部 | 系統產生的利息和集章獎勵不能單獨撤銷；撤銷某筆任務時，若它觸發過集章獎勵，獎勵會一起撤銷 |

- 扣錢、花費、兌換前都會檢查存款，不會出現負數。
- 月息 = floor(存款 ÷ 每滿金額) × 每月利息。例如存款 2,350 元、設定每滿 1,000 元給 10 元，利息就是 20 元。同一個月只會發一次。

## 已知限制
- 長輩如果把網頁「加入主畫面」後用 App 模式開啟，iOS 上的 Google 登入彈出視窗偶爾會失敗。遇到這種情況，請改用 Safari 或 Chrome 的書籤開啟。
- Google 登入憑證 1 小時後過期。網頁會嘗試自動續登，續不了時會顯示登入按鈕，再按一次就好。
- Apps Script 每次呼叫大約需要 1–2 秒，這是 Google 平台本身的延遲。

## 本機測試
`test/` 資料夾裡有一套模擬 Apps Script 環境的後端測試（Node）和前端自動化測試（Playwright），涵蓋權限、集章、撤銷、月息、小孩唯讀等流程。
